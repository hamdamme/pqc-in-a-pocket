# Sources

This guide paraphrases concepts in its own words. These primary sources define the standards and provide the authoritative details:

- [NIST Post-Quantum Cryptography project](https://csrc.nist.gov/projects/post-quantum-cryptography) — standards overview and current project status.
- [FIPS 203: ML-KEM](https://csrc.nist.gov/pubs/fips/203/final) — key-encapsulation mechanism standard.
- [FIPS 204: ML-DSA](https://csrc.nist.gov/pubs/fips/204/final) — digital signature standard.
- [FIPS 205: SLH-DSA](https://csrc.nist.gov/pubs/fips/205/final) — stateless hash-based digital signature standard.
- [NIST PQC FAQs](https://csrc.nist.gov/projects/post-quantum-cryptography/faqs) — answers about the standards and implementation details.
- [RFC 9180: Hybrid Public Key Encryption](https://www.rfc-editor.org/rfc/rfc9180) — a hybrid construction combining a KEM, KDF, and AEAD.
- [NIST: What is post-quantum cryptography?](https://www.nist.gov/cybersecurity-and-privacy/what-post-quantum-cryptography) — an introductory overview.
